# Hardball glossary

Public writing rule: spell out an acronym the first time it appears in a public section, then use the shortened form. The dashboard keeps this glossary available for technical terms that would make chart labels too long.

| Term | Meaning |
| --- | --- |
| Major League Baseball (MLB) | The professional baseball league covered by this project. |
| Average annual value (AAV) | The annualized value used to compare a contract or prior contract anchor. |
| Wins above replacement (WAR) | A model-based estimate of wins contributed above a replacement-level player. |
| Weighted runs created plus (wRC+) | A park-adjusted hitting index where 100 is league average. |
| Weighted on-base average (wOBA) | A weighted measure of offensive contribution by outcome. |
| Fielding independent pitching (FIP) | A pitching estimate based on events most controlled by the pitcher. |
| Strikeout minus walk rate (K-BB%) | Strikeout rate less walk rate. |
| Earned run average (ERA) | Earned runs allowed per nine innings. |
| Walks plus hits per inning pitched (WHIP) | Walks and hits allowed per inning pitched. |
| Injured list (IL) | The official roster status used for player absence records. |
| National Baseball Hall of Fame and Museum (NPB) | Japanese professional baseball source used for the posted-class exhibit. |
| Relevance-based prediction (RBP) | The transparency concept used for evidence stability before acting on a prediction. |
| Hakes-Sauer test | The pricing comparison method used here to test whether skills and cost move proportionally. |

Technical source terms and team abbreviations remain in their original form where they are identifiers, file names, or source labels.
